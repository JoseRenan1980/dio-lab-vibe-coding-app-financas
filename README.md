# Projeto VibeFinanças

## Resumo
VibeFinanças é um protótipo de fluxo conversacional para registro rápido de transações via chat, pensado para testes com Lovable ou Landbot e persistência em Google Sheets via webhook. Este repositório contém placeholders e artefatos iniciais para facilitar integração, testes e documentação do fluxo.

## Conteúdo do repositório
- **assets/screenshots/** — pasta de capturas de tela (contém `.gitkeep` como placeholder)  
- **flow_description.md** — descrição do fluxo conversacional e variáveis usadas  
- **sheet_sample.csv** — amostra de dados para testes e integração com Google Sheets  
- **README.md** — este arquivo

## Pré requisitos
- Git instalado  
- Navegador para acessar Lovable ou Landbot  
- Conta Google com Google Sheets para integração via webhook (opcional para testes)
